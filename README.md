# Library Management System

## Project Description

A Python-based Library Management System developed to manage books, members, and library issue/return records efficiently. The system uses JSON file storage to maintain data.

## Features

- Add and manage books
- Add and manage members
- Issue books
- Return books
- Search records
- View library records
- JSON-based data storage
- File handling
- Exception handling
- Simple menu-based interface

## Technologies Used

- Python 3
- JSON
- File Handling
- Functions
- Lists and Dictionaries

## How to Run

1. Download or clone this repository.
2. Open the project in Python or an IDE.
3. Run `library_management_system.py`.
4. Follow the menu options displayed on the screen.
